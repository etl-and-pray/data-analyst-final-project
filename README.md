# Data Analyst Junior: Итоговый проект — Анализ эффективности маркетинговых кампаний спортивного магазина

Комплексное исследование и практический проект по анализу данных крупного магазина спортивных товаров. Работа охватывает полный цикл продуктовой аналитики: от сырых данных из реляционной базы до предиктивного моделирования и бизнес-отчетности.

## Описание бизнес-задачи
Предприятию необходимо оценить результативность прошедших маркетинговых кампаний, сегментировать аудиторию для персонализированного подхода и построить предиктивную модель склонности клиентов к покупке для запуска новой кампании в целевом регионе.

Исследование состоит из пяти ключевых этапов:
1. **Предобработка данных:** подключение к SQLite базе данных (`shop_database.db`), фильтрация по стране с кодом `32`, очистка пропусков, обработка текстовых полей (названия товаров, цвета) и объединение таблиц (`personal_data`, `personal_data_coeffs`, `purchases`).
2. **Бинарная классификация:** восстановление утерянных данных о поле клиентов с помощью обучения модели машинного обучения на полных датасетах с оценкой качества по метрике F-мера.
3. **A/B-тестирование:** оценка эффективности первой маркетинговой кампании (персональная скидка через email-рассылку) на основе контрольных и тестовых групп (`ids_first_company_positive.txt` / `ids_first_company_negative.txt`), расчет метрик и формирование бизнес-рекомендаций.
4. **Кластеризация аудитории:** выделение клиентских кластеров, анализ их покупательских предпочтений (предпочитаемые товары, влияние скидок) и разработка стратегий взаимодействия с каждой группой.
5. **Модель склонности к покупке:** построение предиктивной модели для жителей конкретного региона (страна 32, город 1188) для прогнозирования покупки определенного товара при коммуникации.
